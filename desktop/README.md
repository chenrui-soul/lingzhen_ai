# 灵帧AI桌面版 V0.12.1

当前版本是灵帧AI内测保护基线，包含一密钥一租户、自定义模型网关、豆包多账号管理、独立账号环境、并发任务、实时任务坞、结果回传、创作首页、文本创作、素材与项目管理、无限画布及短剧生产模板。

V0.12.1 增加签名远程连接配置、主备域名自动切换与缓存、普通租户服务器地址完全隐藏，以及管理员验证后的隐藏服务器切换入口。正式发布时需要为客户端配置一个长期稳定的 HTTPS 配置引导域名；实际统一业务域名和备用域名可在密钥管理中心后台随时修改。

## 运行

```powershell
npm install
npm start
```

## 构建 Windows 租户安装包

```powershell
npm install
npm run configure:bootstrap -- https://config.example.com
npm run preflight:dist
npm run dist:win
```

构建结果默认输出到 `dist-tenant/`。租户安装包不得包含开发机的 `data/`、账号 Profile、Cookie、模型密钥、日志或备份。

## 当前范围

- 原品牌 Logo 与桌面科技感 UI
- 密钥激活与租户数据隔离
- 自定义模型厂商、API 密钥、模型能力与生成参数
- 豆包独立账号环境、多账号并行与同账号排队
- 实时任务坞、失败识别、安全重试与视频结果回传
- 创作首页、文本创作、素材中心、项目管理和任务中心
- 无限画布、节点信息传递、真实模型节点执行和短剧模板

`submission_unknown` 不会自动重提；验证码必须由用户手动处理。
