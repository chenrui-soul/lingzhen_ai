# Wave 4：桌面身份续期、用户数据联网与 Bootstrap 聚合

## 状态：已完成

## 目标

1. Access Token 到期前自动刷新，业务请求 401 仅刷新并重试一次。
2. 所有桌面主动操作使用服务端权限列表统一门禁。
3. 豆包账号按当前用户 + 当前租户隔离并同步非敏感摘要。
4. 项目、素材、对话和任务同步脱敏元数据快照。
5. Bootstrap 聚合积分、模型、Skill、豆包账号和最近项目，保持 `schemaVersion=1`。

## 完成内容

- 后端新增 V6 `desktop_data` schema、回滚脚本和分层 Workspace API。
- Workspace Snapshot 使用 `expectedRevision` 乐观锁，冲突返回 409，不静默覆盖。
- 桌面端新增自动续期、刷新 Promise 去重和统一 `authenticatedRequest()`。
- 本地目录增加用户作用域认领：首位历史用户保留旧目录，其他用户进入独立目录。
- Workbench 原子保存后 debounce 同步；敏感字段、本地路径、签名结果地址不会上传。
- 豆包账号注册表保存 `ownerUserId`，跨用户读取直接拒绝。
- 网络失败后 5 秒有界重试；豆包账号仅按显式删除事件同步删除，空列表不批量清远端。
- 积分账户由应用角色只读并允许首次创建，余额变更不开放直接 UPDATE 权限。
- 全量回归由旧密钥认证基线切换为用户身份 + Wave 4 同步基线。
