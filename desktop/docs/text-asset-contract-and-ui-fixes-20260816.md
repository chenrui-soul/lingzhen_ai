# 文本创作共享素材契约与界面修复实施记录

- 实施日期：2026-08-16（Asia/Shanghai）
- 批次：文本创作批次 B 补充批次 / 共享素材契约
- 状态：实现与回归测试完成，隔离测试版可预览
- 边界：未修改豆包、无线画布、模型网关、统一调度器和任务中心

## 本批次目标

1. 修复文本创作左右侧栏收起后显示大块无意义空白的问题。
2. 让正文、版本及素材预览窗口可由用户双向拖动调整尺寸。
3. 修复“新建创作”按钮无效的问题。
4. 开启文本工作区与素材中心的共享文本素材契约，使摘录成为素材中心正式素材，而不是工作区私有副本。

## 实施结果

### 侧栏收起状态

- 左侧栏收起后保留竖排“目录”提示和展开入口。
- 右侧栏收起后保留竖排“协作”提示和展开入口。
- 三栏高度跟随窗口可用高度变化，800px 高视口不再被固定最小高度撑出工作区。
- 正文编辑区域自动吸收新增高度，历史栏与编辑器保持等高。

### 可调整预览窗口

- 正文预览、历史版本预览、文本素材预览、插入确认和摘录窗口支持 `resize: both`。
- 设置了最小与最大尺寸边界，窗口调整后内部内容保持滚动可读。
- 素材中心通用预览窗口同步采用可调整尺寸契约。

### 新建创作

- 移除不稳定的浏览器原生 `prompt()`。
- 使用桌面内自定义弹窗录入标题和创作类型。
- 支持回车提交；创建成功后立即打开新创作。

### 共享文本素材契约

- 主进程数据桥新增 `createTextAsset(input)`。
- 新增 IPC `assets:create-text`，并通过 preload 暴露 `assets.createText(input)`。
- “提取词句”可填写摘录名称并保存到素材中心。
- 保存结果是正式 `.txt` 文本素材，具有独立 `assetId`，可由素材中心和文本工作区共同读取。
- 保留 `sourceAssetId`、`sourceProjectId`、`sourceLocation`、conversation 来源、标签和备注。
- 校验空内容、10 MB 上限、来源素材存在性、来源素材项目一致性和租户隔离。
- 保存后刷新同源文本素材库；不建立第二套素材数据库，也不复制共享调度逻辑。

## 2026-08-17 交互补丁

根据真实界面复核，补充修复两项此前测试遗漏：

- 收起状态虽然已显示“目录/协作”，但内联宽度变量仍保留展开尺寸。现已让收起状态直接写入 46px 轨道宽度，展开时恢复用户保存宽度。

真实 Electron 补丁验收为 8/8，通过项目包括：左右栏实际宽度均为 46px，以及四个素材操作按钮逐个点击成功。补丁快照位于 `backups/text-asset-contract-20260816/postfix-20260817-0138/`。
