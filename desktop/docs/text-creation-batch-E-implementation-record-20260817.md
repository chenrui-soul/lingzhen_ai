## 本批次实现

### 专业模板

- 小说：题材、主题、一句话梗概、叙事视角、语言基调和目标篇幅；
- 故事：目标读者、主题、故事前提、核心冲突、关键转折和结局方向；
- 剧本：剧本形式、集数/幕数、一句话梗概、主题、基调和目标时长；
- 分镜：比例、视觉风格、总时长、节奏和连续性原则，镜头节点支持景别、运镜、时长、画面、对白、声音和提示词；
- 提示词：目标模型、媒介、主体、场景、动作、风格、镜头、光线、负向约束和变量；
- 广告文案/短视频文案：产品、人群、渠道、目标、卖点、语气、行动号召和合规约束；
- 人物设定和世界观旧类型使用人物/世界观兼容模板。

### 结构化工作台

- 左侧作品结构区支持顶级节点、子节点、选中编辑和从正文标题显式提取；
- 右侧增加“结构创作”标签，包含模板字段、章节/场景、人物与世界、时间线和结构版本五种模式；
- 人物卡支持姓名、角色定位、目标、冲突、外形服装、声音和人物关系；
- 世界观支持设定名称、类别、规则限制、详细说明和备注；
- 时间线支持时间、地点、人物、事件和后果；
- 提示词变量支持变量名、占位符、当前值和使用说明；
- 节点删除会级联删除子节点，不会产生孤立循环节点；
- 支持结构撤销、重做、手动快照和快照恢复。

### 纯文本兼容和安全路径

- 九类旧文本会话继续使用原 `type` 打开；
- 旧会话初次打开只创建瞬时兼容文档，不立即写入结构存储；
- 用户第一次编辑结构后，才按 `tenantId + projectId + conversationId` 保存结构文档；
- 结构字段和中央正文分开保存，结构编辑不会静默覆盖正文；
- 结构稿只能在预览窗口中点击“确认插入到光标”后写入正文；
- 模板切换前保存结构快照，并保留节点、人物、世界观和时间线；
- Markdown 和 JSON 导出都是人工显式操作；
- JSON 导出使用字段白名单，不导出 API Key、Cookie、认证头、服务地址或密码。
