## 本批次实现

### 素材中心同源

新增 `text-workspace-assets.js`，直接调用 `window.lingframe.workbench.bootstrap()`。

文本素材库只读取返回的正式素材对象和 `assetId`，不复制素材文件，不写第二套素材数据库，不修改素材中心主逻辑。

### 当前项目筛选

- 只显示当前文本会话项目的素材；
- 只显示 `type === "text"` 的素材；
- 自动排除已删除和已归档素材；
- 支持名称、原始文件名、标签、备注和来源搜索；
- 跨项目拖放和引用会拒绝。

### 来源分类

- AI 生成；
- 本地上传；
- 文献参考；
- 项目资料；
- 历史版本。

来源基于素材中心正式 `source` 和元数据推断显示，不创建新的素材类型字段。

### 素材操作

- 查看原文：通过 `assets.readText(assetId)` 读取正式素材内容；
- 复制：复制文本内容，不复制文件；
- 提取词句：用户选择来源文本后进入插入预览；
- 插入正文：显示可编辑插入预览，确认后才写入正文；
- 拖入正文：携带 `assetId`、项目 ID 和来源证据，落点后进入相同预览；
- 重复插入保护：同一素材与同一摘录不会静默重复写入；
- 来源追踪：显示素材名、原始文件名、来源、更新时间和 `assetId`。

正文写入通过现有 textarea 的 `input` 事件进入文本工作区自动保存和版本逻辑，没有绕过文本会话保存机制。

### 同步策略

文本素材库在以下时机重新读取素材中心：

- 手动点击刷新；
- 窗口重新获得焦点；
- 页面从隐藏恢复可见；
- 文本页面打开期间每 8 秒同步一次。

素材中心的重命名、删除、归档、恢复和项目变化可刷新到文本素材库视图。
