## 本批次实现

### 质量检查

右侧新增“检查/导出”标签，中央原“导出”入口同步升级为“检查/导出”。检查必须由用户手动运行，结果只生成问题卡、位置和修改建议，不会自动替换、插入或改写正文。

四类检查包括：

- 连续性：人物卡重名、结构人物引用缺失、人物外观冲突、时间线倒序或缺少时间、同名事件地点冲突、同名场景地点冲突、孤立结构节点、道具丢失/损坏后无过渡再次使用；
- 错别字：常见错词、疑似重复词，保留原位置、行列、上下文和人工核对建议；
- 格式与段落：行尾空格、制表符、连续空行、重复标点、中文上下文半角标点、括号/引号不配对、超长段落、剧本场景标头和分镜关键字段缺失；
- 表达风险：绝对化排名、保证性承诺、医疗功效、金融收益、诱导紧迫、侵权/授权暗示和歧视性表达。

检查结果区支持按全部、连续性、错别字、格式段落和表达风险筛选。正文变化后旧报告明确标记为“已过期”，不会用旧结果回写正文。

正文问题卡点击后恢复正文编辑器焦点并选择原词；结构问题卡点击后回到原 `conversation` 的结构创作标签，并定位时间线、人物卡或章节/场景节点。

风险提示只作为辅助，不替代人工校对、法律审核或平台合规审核。

### 统一安全导出

同一面板提供五种人工显式导出：

- TXT：当前正文；
- Markdown：标题、类型、正文和当前会话结构附录；
- JSON：项目、conversation、正文和结构字段白名单；
- 剧本格式：场次、场景标头、出场人物、动作、对白目标和正文参考；
- 分镜表 CSV：镜头号、标题、景别、机位/运镜、时长、画面、对白、声音、提示词和备注。

导出继续保持 `projectId + conversationId` 一对一绑定。结构数据只读取批次 E 已保存的原会话结构，不创建新结构、不重新生成内容、不创建任务。

JSON 和结构附录采用字段白名单，并过滤 `apiKey`、Cookie、认证头、Token、Secret、服务地址、账号 Profile、Credential 和密码类字段。批次 F 不读取模型网关认证配置。

### 键盘、焦点与显示适配

- `Ctrl+Alt+Q`：打开质量面板并运行所选检查；
- `Ctrl+Alt+E`：打开安全导出区域；
- `F6` / `Shift+F6`：在目录、标题、正文、底部操作和右侧协作区之间切换焦点；
- `Escape`：窄屏关闭质量覆盖层并恢复原编辑焦点；
- 问题卡、分类标签、导出卡和表单控件均提供可见键盘焦点；
- 900 px 以下不继续压缩正文，质量面板使用临时右侧覆盖层；
- 144 DPI 及以上提高主要文字和点击区尺寸，导出卡点击高度不低于 44 px；
- 右侧五个标签允许换行，避免结构创作和检查导出入口互相挤压。
