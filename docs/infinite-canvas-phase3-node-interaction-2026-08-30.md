# 无限画布阶段三执行报告

日期：2026-08-30

## 范围

本阶段只修改无限画布模块的节点编辑、节点/分组拖动、编辑器显隐和运行期间交互。未修改登录、租户、任务中心、豆包管理、模型网关或其它页面业务逻辑。

## 已实施

### 1. 节点与分组拖动事务

- 标题栏按下只记录起点、原始坐标和编辑器状态，不立即写入历史。
- 鼠标移动超过 4px 后才进入真实拖动并创建一次历史快照。
- 节点使用 Pointer Capture，拖动不因指针离开卡片而中断。
- 分组拖动同步移动分组和成员节点，并按当前缩放比例换算位移。
- 拖动中只更新节点/分组 DOM、关联连线和分组边界，不调用整画布渲染。

### 2. 编辑器自动隐藏与恢复

- 真实拖动开始时隐藏右侧检查器、浮动节点编辑器和上下文菜单。
- 隐藏使用 `visibility` 和 `pointer-events`，保留右侧栏布局宽度，避免画布突然跳动。
- 节点拖动释放后自动打开当前拖动节点的编辑器。
- 分组拖动释放后恢复拖动前的选区、编辑对象、编辑器折叠状态和 tab。
- 拖动结束后阻止一次误触发的 click，避免节点被错误切换或重复打开。

### 3. 取消与历史记录

- `Esc` 在输入框判断前处理，拖动中可取消本次拖动。
- 取消时恢复节点、分组、成员节点和连线位置。
- 取消会移除本次拖动临时创建的历史快照，不产生撤销记录。
- 正常释放只保存一次坐标变更，并保持当前视口不变。

### 4. 运行期间可操作

- 运行中的节点禁止重复提交，给出明确提示。
- 当前运行节点的节点卡片、检查器、运行面板和浮动编辑器按钮显示禁用状态。
- 其它未运行节点仍可选择、编辑和运行。
- 任务状态继续使用阶段一的局部刷新，不通过轮询反复重建整个画布。
