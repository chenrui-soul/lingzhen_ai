# 无限画布优化方案（修订版）

## 1. 产品定位

将无限画布从“专业节点编排器”升级为“普通用户可以直接创作、专业用户可以深入编排”的 AI 创作空间。

核心体验：

```text
默认像小云雀一样容易开始
创作卡片像 LibTV 一样直接
深入使用时保留灵帧 AI 的工作流能力
```

## 2. 修改边界

本方案只针对无限画布模块。

允许修改：

- 无限画布空状态、节点库、资源面板、节点编辑器和运行现场。
- 无限画布相关 JavaScript、CSS 和已有画布适配层。
- 无限画布入口的必要绑定。

禁止修改：

- 任务中心、豆包管理、系统设置和其他导航页面的业务逻辑。
- 后端接口和公共数据结构，除非后续确认已有接口无法支持画布需求。
- 其他页面的布局和样式。

### 2.1 本轮固定产品决策

- 本轮只优化无限画布模块；其它页面、任务中心、豆包管理、登录、租户和模型网关保持原逻辑。
- 首屏生成按钮通过本地校验后，立即创建/打开无限画布；远程任务在画布内后台提交和运行。
- 首屏必须支持文字、图片、视频、音频、模型/通道和生成参数的完整配置。
- 短剧生产流程暂时隐藏，不从历史画布中删除，不影响历史数据兼容。
- 节点实际开始拖动时编辑器立即隐藏；拖动结束后自动打开当前拖动节点的编辑器。
- 运行任务不能锁死画布；节点、面板、视口和媒体预览必须保持可操作、稳定和可恢复。

## 3. 首屏方案：灵感，即刻成帧

空白画布中心改为：

```text
灵感，即刻成帧

[描述你的创意，例如：制作一部古风悬疑短剧]

[故事脚本] [角色设定] [场景参考]
[图片生成] [视频生成]

＋ 上传素材    从项目资产选择    从模板开始

也可以从节点库拖入节点，或在画布空白处右键创建
```

输入框是首要入口，节点库是专业入口。

快捷入口行为：

- 故事脚本：切换为文本生成预设，提交后创建文本输入节点和文本生成节点，不创建短剧流程专用节点。
- 角色设定：切换为图片生成预设，参考素材默认角色标记为“人物”，提交后创建文本、人物参考和图片生成节点。
- 场景参考：切换为图片生成预设，参考素材默认角色标记为“场景”，提交后创建文本、场景参考和图片生成节点。
- 图片生成：切换为通用图片生成预设，用户自行添加人物、场景、道具或风格参考。
- 视频生成：切换为视频生成预设，显示豆包/模型网关、比例、时长和媒体参考参数。

“完整短剧流程”暂时不作为首屏入口，后续恢复短剧产品线时再重新设计。

用户在创作台点击生成后，系统先完成本地输入、素材和模型参数校验；校验通过即进入无限画布并创建对应节点，远程任务随后在画布内后台提交，结果再回传到对应节点。不再要求用户先手动创建文本节点才能开始。

### 3.1 首屏创作台：输入、素材、参数、生成一体化

当前首屏只有文本输入框，用户还必须进入画布后再添加参考素材、选择模型和点击节点运行。首屏应直接完成一次完整生成配置；快捷入口只负责切换创作类型和默认参数，不能替代完整创作台。

建议结构：

```text
┌──────────────────── 灵感，即刻成帧 ────────────────────┐
│ 你的创意                                               │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 输入故事、画面描述或视频动作……                     │ │
│ └────────────────────────────────────────────────────┘ │
│                                                        │
│ 参考素材                                               │
│ [＋图片] [＋视频] [＋音频] [从项目资产选择]             │
│ [人物图 预览 ×] [场景图 预览 ×] [参考视频 ×]            │
│                                                        │
│ 生成类型 [文本/图片/视频]  通道 [模型网关/豆包]         │
│ 模型 [选择模型] 账号 [自动/指定账号]                    │
│ 比例 [自动/16:9/9:16/1:1] 时长 [按模型支持范围选择]      │
│                                                        │
│                         [生成并进入无限画布]            │
└────────────────────────────────────────────────────────┘
```

#### 3.1.1 创作类型

- 默认根据用户点击的快捷入口切换生成类型：故事脚本进入文本模式，图片生成进入图片模式，视频生成进入视频模式。
- 用户可在创作台手动切换文本、图片和视频；切换只改变可见参数，不清空已经添加的素材和文字。
- 类型切换后保留素材，但提示当前类型会使用哪些素材，例如图片生成使用图片/文本，视频生成使用文本/图片/视频/音频。
- 不再显示“完整短剧流程”入口，也不自动生成一串短剧节点。

#### 3.1.2 文本输入

- 文本输入框支持多行、自动增高、粘贴长文本和 `Ctrl/Cmd+Enter` 生成。
- 提供字数/长度提示，但不截断用户内容；超过模型限制时在生成前明确提示可压缩内容。
- 输入框内容实时保存为当前画布草稿，刷新或切换面板后不丢失。
- 生成后，原始文字以“文本内容”写入画布文本节点；不能以 `.txt` 文件或文本资产 ID 传给下游模型。
- 如果用户只输入文字没有添加素材，仍可直接生成；如果模型需要参考素材，在生成前给出明确缺项提示。

#### 3.1.3 参考图片、视频、音频

参考素材区域必须支持四种入口：

- 点击“添加图片/视频/音频”打开本地文件选择器。
- 将本地文件拖入素材区域直接上传。
- 点击“从项目资产选择”打开项目资产选择器，在当前创作台内完成选择，不能跳转到资源库页面。
- 从左侧资源抽屉拖入创作台，或从画布已有节点选择“引用为参考素材”。

素材卡片规范：

- 添加后立即显示缩略图、文件名、素材类型、加载状态和删除按钮。
- 图片显示画面预览；视频显示封面、时长和播放按钮；音频显示波形/音频图标、时长和播放控制。
- 每个素材可设置角色标签：人物、场景、道具、动作参考、风格参考、背景音乐或其它。
- 支持替换素材、取消上传和重新加载；上传失败保留失败卡片，不静默消失。
- 同一素材重复添加时提示“已添加”，不重复上传；同一项目资产可以在不同节点中复用。
- 支持限制数量、格式和大小，并在选择文件后立即提示不支持原因。
- 素材尚未完成上传时，生成按钮不可提交；上传完成后才进入可生成状态。
- 图片、视频、音频作为媒体 payload/参考素材传递；只有文本文件需要提取文本内容后作为文字传递。

素材使用预览：

- 点击素材卡片主体打开大图、大视频或音频预览，不关闭创作台。
- 预览关闭后返回原滚动位置和焦点。
- 素材预览层和生成任务互不阻塞，不能因为查看参考视频而停止任务状态更新。

#### 3.1.4 模型、通道和生成参数

参数区根据生成类型和所选通道动态显示，但不隐藏生成按钮。

通用参数：

- 生成类型：文本、图片、视频。
- 调用通道：模型网关或豆包；只显示当前配置中可用的通道。
- 模型：按通道过滤可用模型，显示模型名称、能力类型和不可用原因。
- 账号/账号组：豆包使用自动选择或指定已配置账号；没有可用账号时显示配置提示。
- 生成比例：自动、16:9、9:16、1:1 及当前模型支持的其它比例。
- 生成数量：仅在对应模型支持时出现，默认 1，不能在不支持的通道显示无效选项。

图片参数：

- 图片模型、比例、清晰度/质量、生成数量和参考图使用方式。
- 参考图角色在提交前可核对，至少区分人物、场景和风格参考。

视频参数：

- 豆包模型、豆包账号/账号组、比例、时长、分辨率或质量档位（仅显示后端/模型实际支持的选项）。
- 文字提示词、人物图、场景图、参考视频和音频分别显示绑定状态。
- 视频生成前展示输入摘要：提示词长度、图片数量、视频数量、音频数量、模型、账号和预计消耗（如果现有接口提供）。
- 视频参数变化后同步写入视频生成节点；节点外框比例也同步变化，详见第 8 节。

参数交互规则：

- 切换通道或模型时保留用户文字和素材；只清理当前模型不支持的参数，并提示被清理项。
- 模型加载中显示骨架状态，旧模型仍可查看但不可重复提交。
- 模型、账号、比例和时长选择必须使用当前已配置数据，不在无限画布内复制登录、豆包管理或网关配置逻辑。
- 余额不足、账号未配置、模型不可用、参数不支持时，生成按钮保持可见但置为不可用，并在按钮旁说明原因。

#### 3.1.5 生成按钮与状态

生成按钮统一放在创作台右下角。本地校验通过后，点击按钮必须立即创建/打开无限画布，不等待网关或豆包接口响应，也不等待图片或视频生成完成；画布节点先显示“提交中/排队中/生成中”，结果完成后再原位回传。

文案随状态变化：

```text
可生成       生成并进入无限画布
校验中       正在检查输入…
上传中       等待素材上传完成
提交中       正在提交任务…
排队中       已提交，等待模型处理
生成中       已进入画布，后台生成中
完成         结果已回传画布
失败         重试生成
```

提交规则：

- 点击一次只允许创建一个生成请求，提交后立即禁用重复点击，但不能锁死画布其它操作。
- 提交前进行文字、素材类型、模型、账号、比例和时长校验；错误就地显示并定位到对应字段。
- 生成过程中允许关闭创作台、切换画布、拖动节点和打开资源库；任务继续在后台运行。
- 本地校验通过后先进入无限画布，立即创建文本节点、参考素材节点/引用关系、生成节点和任务占位状态；任务提交在画布中后台完成，不阻塞页面切换。
- 进入画布后，生成节点显示实时任务状态和取消/查看运行现场入口；图片、视频或音频完成后原位回传为结果资产，节点尺寸和预览自动更新。
- 如果任务提交失败，错误显示在画布生成节点和运行现场，保留全部输入和参数并提供重试；如果页面切换失败，草稿和任务绑定仍可恢复。
- 生成失败后保留全部输入和参数，点击重试时复用上次配置，不重复上传已成功的素材。
- 任务处于提交中或排队中时允许取消；取消前给出一次轻量确认，确认后只取消当前任务，不删除输入节点、参考素材和已有结果版本。
- 任务已经进入不可取消的生成阶段时，按钮改为“停止关注/隐藏状态”，明确说明不会撤销已提交的远程任务，避免用户误以为已取消。
- 取消、失败和重试都记录在生成节点的版本/运行历史中，重试生成新的 `requestId`，不复用已经完成任务的 ID。
- 用户关闭或离开创作台时保存草稿；再次打开时恢复文字、素材、类型和参数。

#### 3.1.6 与快捷入口的关系

- 快捷卡片是“预设模式”，点击后展开/聚焦创作台并填入默认类型，不直接创建无意义的节点框。
- “上传素材”和“从项目资产选择”直接操作创作台素材区，不再只跳转左侧资源库。
- “从模板开始”只保留基础图片生成、视频生成和素材处理模板；短剧生产模板暂时隐藏。
- 当创作台已经存在文字或素材时，切换快捷入口必须二次确认或提供“保留当前内容/清空重来”两个选项，防止误清空。

### 3.2 首屏生成数据和状态契约

为避免“先跳转还是先提交”“文本文件还是文字 payload”等理解偏差，首屏创作台必须统一生成草稿和提交信封。优先复用现有无限画布数据结构，不在其它模块复制一套模型或豆包配置。

```js
composerDraft = {
  mode: "text | image | video",
  promptText: "用户输入的文字内容",
  references: [
    { assetId, type: "image | video | audio", role, source: "local | project | canvas" }
  ],
  route: {
    channel: "model-gateway | doubao",
    providerId, modelId, accountId, accountGroupId,
    doubaoModel, ratio, duration, quality, count
  },
  status: "editing | validating | ready | creating-canvas | submitting | failed",
  requestId,
  canvasId
}
```

提交时生成不可变的 `executionEnvelope`：

```js
executionEnvelope = {
  requestId,
  canvasId,
  prompt: promptText,
  assetIds: references.filter(item => ["image", "video", "audio"].includes(item.type)).map(item => item.assetId),
  referenceAssets: references.map(item => ({ assetId: item.assetId, type: item.type, role: item.role })),
  route,
  inputManifest,
  creationSource: "infinite-canvas-v2"
}
```

`inputManifest` 必须明确记录文字和媒体的来源，不能只传一个混合数组：

```js
inputManifest = {
  textBlocks: [
    { sourceNodeId, text, enabled: true, transferMode: "text" }
  ],
  assetBindings: [
    { sourceNodeId, assetId, type: "image | video | audio", role, enabled: true, transferMode: "reference" }
  ]
}
```

画布节点关系固定为：

```text
文本输入节点 ──────────────┐
人物/场景/道具素材节点 ────┼─→ 图片/视频生成节点 ─→ 结果资产节点
参考视频/音频节点 ────────┘
```

- 文本输入节点通过文字端口连接，生成节点读取文本内容。
- 图片、视频和音频通过媒体端口连接，生成节点读取资产 ID、类型和角色。
- 不支持的输入类型显示为未使用状态，不能伪装成文本或静默丢弃。
- 生成结果节点保存任务 ID、资产 ID、版本号、比例和来源生成节点，后续重试生成新版本，不覆盖旧结果。

执行顺序固定为：

1. 本地校验文字、素材、模型、账号和参数。
2. 生成 `requestId`；首页创作台直接生成时创建全新的目标画布，已有画布内运行节点时才使用当前画布。
3. 在画布中创建文本节点、媒体引用节点、生成节点和待运行状态。
4. 使用同一个 `requestId` 异步提交 `executionEnvelope`。
5. 任务绑定 `canvasId + nodeId + requestId`，状态和结果只回填到对应生成节点。

画布创建策略：

- 从首页创作台直接点击“生成”时，永远新建一个画布，标题使用“生成类型 + 日期时间”，用户可立即重命名；不得复用或覆盖当前画布。
- 只有用户在已有画布内明确点击“运行当前节点/继续生成”时，才允许使用当前画布。
- 不得把首屏生成内容覆盖到已有画布；如果用户从资源库或节点库手动创建内容，则按当前画布操作。
- 画布创建失败时停留在创作台并保存草稿；画布创建成功后即使远程任务提交失败，也保留已创建节点。

补充规则：

- `prompt` 只能是文字内容；文本资产 ID、`.txt` 文件路径和文件对象不得进入 `assetIds` 或媒体参考列表。
- 同一个 `requestId` 重试页面切换或网络请求时必须幂等，不得创建重复任务或重复节点。
- 画布创建成功但任务提交失败时，保留节点和完整输入，节点显示“提交失败/重试”；不能回退到空白首页抹掉用户内容。
- 任务提交成功但窗口关闭时，应用重启后按 `requestId` 恢复任务绑定和运行状态，不重新提交。
- 结果资产回传只更新对应生成节点的 `outputAssetId/outputVersion`，不覆盖原始文字和参考素材引用。
- 状态转换必须可追踪：`editing → validating → creating-canvas → submitting → queued → generating → completed/failed/cancelled`；异常恢复只能回到已有合法状态，不能直接伪造“已完成”。

## 4. 画布元素、资产库、项目资产

三个概念必须分开：

```text
资产库 / 项目资产
        ↓ 引用
     画布元素
        ↓ 执行和生成
   新的项目资产
```

### 4.1 画布元素

只显示当前画布正在使用的内容：

- 角色、场景、道具。
- 图片、视频、音频和文本。
- 输入、处理、生成和输出节点。
- 分组、便签、注释、连线和流程结果。

每个元素支持定位画布、打开编辑、复制、替换素材和移除引用。

### 4.2 资产库

用于跨项目复用：

- 角色库、场景库、道具库。
- 风格参考、提示词和模板素材。
- 图片、视频、音频和文档。

资产库中的资源不能因为画布删除而消失。

### 4.3 项目资产

用于管理当前项目的真实文件和结果：

- 本地上传文件。
- 节点生成结果。
- 任务中心回填的结果。
- 历史版本、失败结果和待确认结果。

项目资产是生成结果的主要归档位置。

资源面板支持搜索、类型筛选、预览、拖入画布、批量选择和引用到多个节点。

## 5. 画布布局

设计原则：

- 节点库默认收起，避免 23 个节点同时占据视觉焦点。
- 资源抽屉按需展开，不永久压缩画布空间。
- 节点编辑器以右侧浮层为主，拖动节点时按 5.4 规则临时隐藏并在结束后恢复。
- 节点本身显示摘要、输入状态和生成结果缩略图。
- 低频高级参数放入“高级设置”。

### 5.1 沉浸式画布模式

当前无限画布仍受到应用通用页面边距、固定左右栏和页面标题区的挤压，导致中央工作区不够大。本次将无限画布改为“画布优先”的专属布局，只改变无限画布路由，不改变其它页面。

目标布局：

```text
┌──────────────────── 极简画布顶栏 ────────────────────┐
│ 返回｜画布名｜保存状态              比例｜主题｜运行 │
├──────────────────────────────────────────────────────┤
│                                                      │
│                    沉浸式无限画布                    │
│                                                      │
│      左侧工具/资源抽屉按需覆盖        右侧编辑器按需覆盖 │
│                                                      │
└─────────────── 浮动缩放/小地图/运行状态 ──────────────┘
```

具体规则：

- 无限画布页面去掉通用工作区的 15px/18px 外边距，画布占满可用客户区。
- 页面标题和说明不再单独占一整行，合并到画布顶栏；顶栏高度控制在 48～56px。
- 左侧节点库、资源库和右侧检查器默认为“抽屉/浮层”，展开时覆盖画布边缘，不重新压缩中央画布。
- 默认进入画布时，左右抽屉保持上次状态；首次进入默认只保留窄工具条，中央区域最大化。
- 提供“沉浸模式”按钮：隐藏左侧抽屉、右侧检查器、底部状态条和非必要工具，只保留画布、返回按钮和退出沉浸按钮。
- 顶栏、工具条、缩放条和小地图使用半透明浮层，不遮挡节点主体；移动到画布边缘时仍可操作。
- 浏览器窗口缩放、应用尺寸变化和右侧面板开关后，保持画布视口的世界坐标中心，不自动执行适应画布。
- 小地图和缩放工具只在鼠标靠近底部或按快捷键时显示，避免长期占用视觉空间。
- 画布背景、网格和节点使用更低对比度的装饰层，突出素材内容和连线，不让外框抢占注意力。

### 5.2 顶部工具栏信息密度

截图中标出的“主题、导出、导入”等工具存在图标和大号文字重复显示的问题。顶部工具栏应采用“图标优先、提示按需出现”的规则：

- 常驻显示清晰图标，不在图标下方或旁边重复显示“主题/导出/导入”等大段文字。
- 鼠标悬停 600ms、键盘聚焦或长按时显示小型 Tooltip，说明名称、快捷键和作用。
- 工具栏按钮统一固定高度、宽度、内边距和垂直对齐，禁止因文字换行、字体变化或窗口缩放出现竖排、下坠和错位。
- “主题”打开主题弹窗；“导出”打开导出格式和范围选择；“导入”打开文件选择或拖拽导入，不直接执行不可逆操作。
- 低频操作收进“更多”菜单；运行、保存状态、撤销/重做等高频操作独立保留。
- 导出/导入按钮只处理无限画布工作流和画布数据，不与项目资产上传混用；资产上传使用创作台或资源面板的专用入口。
- 工具按钮提供 `aria-label`、键盘焦点样式和禁用原因；Tooltip 不能遮挡当前节点或阻止画布操作。
- 画布顶部不再常驻显示重复的模块说明、副标题和大段操作文字；名称、保存状态和必要操作保留在极简顶栏。

### 5.3 画布工作区与创作台的边界

- 空白画布中心只显示一次“灵感，即刻成帧”创作台，不同时显示第二套相同输入说明。
- 用户点击快捷入口时，只切换创作台预设并聚焦对应字段；用户点击“生成”后按 3.2 规则永远新建画布。
- 进入已有画布后，创作台可以作为浮层再次打开，但“生成”仍创建新的生成节点/新画布，除非用户明确点击当前节点的运行按钮。
- 创作台关闭、展开和切换预设不改变画布视口，不隐藏正在运行的节点，不删除输入草稿。

建议状态类名：

```text
lfc-immersive                 画布占满可用空间
lfc-drawer-overlay            抽屉浮层，不改变画布尺寸
lfc-focus-mode                只保留画布和极简顶栏
lfc-node-dragging              正在拖动节点
lfc-editor-hidden-on-drag     拖动期间编辑器隐藏
```

### 5.4 拖动节点时的编辑器行为

拖动节点的首要目标是“看清节点移动到哪里”，编辑器不能继续遮挡画布，也不能因为拖动触发全量重绘。

交互流程：

1. 指针按下节点标题栏时，只记录拖动起点和节点原始位置，不立即判定为拖动。
2. 指针移动超过 4px 后进入拖动状态，立刻执行以下动作：
   - 隐藏节点编辑器/右侧检查器内容；
   - 关闭节点浮动编辑器、放大编辑器和上下文菜单；
   - 暂停编辑器定位计算和输入框焦点恢复；
   - 保留节点选中框、端口和连线；
   - 给画布增加 `lfc-node-dragging` 状态，节点只保留必要的拖动反馈。
3. 拖动过程中直接更新节点 DOM 的位置和连线几何，不重建整个画布 DOM；素材预览、视频元素和其它节点保持原有 DOM 引用。
4. 指针释放后保存新坐标，退出拖动状态，并自动打开当前拖动节点的编辑器；如果拖动前已有编辑器，则恢复原来的 tab、编辑对象和未提交内容；如果拖动前没有编辑器，则打开该节点的默认编辑页。
5. 编辑器恢复不得改变画布视口，不得让输入框跳到错误节点；恢复焦点应放在节点编辑区域，但不能覆盖用户刚刚完成的拖动操作。
6. 如果按下后没有超过 4px 就释放，则按“选择节点”处理，可以打开节点编辑；点击标题栏不能误触发编辑器。
7. 拖动期间按 `Esc` 取消本次拖动，节点和连线恢复到拖动前位置，并恢复拖动前编辑器的显示状态，不修改历史记录。
8. 多选节点和分组拖动时，暂时隐藏编辑器；释放后恢复拖动前的编辑器状态，不把多选中的其它节点误切换成编辑对象。

实现约束：

- `runtime.nodeDrag` 和 `runtime.groupDrag` 增加 `committed`、`moved`、`editorHidden` 标志。
- 拖动开始/移动/结束只调用局部渲染函数，例如 `renderSelection`、`renderEdges`、`applyViewport`；禁止调用 `renderCanvasModule()`。
- 编辑器隐藏必须是可恢复的状态切换，不清空节点数据，也不改变节点执行状态。
- 保存坐标使用节流或指针释放后保存，避免每个像素触发持久化。

## 6. 右侧面板状态

- 未选中节点：显示 AI 创作助手和推荐动作。
- 选中节点：显示节点快捷编辑和输入素材。
- 点击高级设置：显示完整节点参数。
- 运行中：显示任务进度、验证提醒和结果状态。
- 生成完成：显示预览、版本、保存位置和继续生成。

拖动期间右侧面板只执行 5.4 中定义的临时隐藏和恢复，不另行创建空白面板或切换 tab。

其它面板规则：

- 如果用户正在编辑文本，开始拖动前先提交当前输入；提交失败时取消拖动并保留编辑器。拖动结束后重新打开当前拖动节点的编辑器。
- 运行中的节点可以继续拖动、选择、连线和打开其它节点；运行按钮只对目标节点做状态限制。
- 面板打开/关闭不得重置节点位置、视口或媒体播放状态。

## 7. 运行时非阻塞与视口稳定

### 7.1 运行期间保持画布可用

- `runSequence`、`runSingleNode` 和任务轮询采用后台状态更新，不锁定整个画布。
- 运行中仍可新建画布、切换画布、拖入素材、创建节点、移动节点、缩放、平移、打开资源库和查看其它节点。
- 只有当前节点的运行按钮、重复提交按钮和不适用的参数控件进入禁用态。
- 运行状态更新只更新状态徽标、进度条、错误信息和结果引用，不重新创建所有节点。
- 任务轮询不得通过 `renderCanvasModule()` 反复销毁并创建 `<video>`、`<img>`、文本输入框或编辑器。
- 运行现场使用独立的局部列表刷新；点击任务记录时再定位对应画布节点。

### 7.2 视口不回弹

- 视口状态统一保存在当前画布的 `viewport` 中，包括 `x`、`y`、`zoom` 和最近一次交互时间。
- 缩放以鼠标所在画布坐标为锚点，平移以指针起点为基准，二者都不调用自动 `fitView()`。
- 只有用户明确点击“适应画布”时才重置视口；新建节点、任务完成、打开编辑器和面板切换不能触发适应画布。
- 渲染前后校验视口值；状态轮询、窗口 resize 和抽屉切换只重新计算可视区域，不覆盖世界坐标。
- 视口更新与画布数据保存解耦，使用节流保存；保存失败不能回滚当前屏幕位置。
- 鼠标滚轮只在画布空白区执行缩放；节点、输入框、资源列表、编辑器和弹窗内的滚轮交给自身滚动。

### 7.3 局部渲染和性能边界

- 画布分为稳定层和状态层：稳定层包含节点主体、媒体元素和文本编辑器；状态层包含状态徽标、进度、错误提示、临时连线和选择框。
- 节点 DOM 使用稳定的 `nodeId` 复用；任务轮询、选中变化和面板切换不能销毁再创建同一个节点的媒体元素。
- 任务状态更新只刷新对应节点和运行记录；视口平移只更新世界层 transform；节点拖动只更新被拖节点、关联连线和选择框。
- 拖动和缩放中的视觉更新使用 `requestAnimationFrame` 合帧；保存、统计和任务状态写入使用防抖/节流。
- 画布存在大量节点时按可视区域优先渲染；不可见节点保留数据和连接关系，不因离开视口而丢失结果。
- 图片和视频使用稳定的加载策略：旧资源在新资源加载完成前保留，避免替换瞬间出现空白闪烁；资源确认失效后才显示错误占位。
- 运行状态、视口状态、选择状态和编辑器状态分离保存，任何一类状态变化不能隐式触发其它状态重置。
- 每次局部更新记录来源和目标节点，便于开发测试确认没有误触发全量 `renderCanvasModule()`。

## 8. 节点尺寸、媒体预览和放大查看

### 8.1 节点尺寸模型

节点不再统一使用固定的 `248px × 140px` 卡片。每个节点增加展示元数据：

```js
presentation: {
  width: 320,
  height: 220,
  aspectRatio: "16 / 9",
  fit: "cover",
  userResized: false
}
```

规则：

- 图片节点按图片实际宽高比计算内容区，视频节点按视频实际比例或生成节点选择的比例计算。
- 生成节点选择 16:9、9:16、1:1 等比例后，节点内容区同步变化，节点外框跟随变化。
- 自动尺寸只改变内容区和整体高度，不改变节点在画布中的锚点位置。
- 宽高设置最小/最大边界，避免超宽素材挤出画布或极小素材无法操作；建议宽度 240～520px。
- 用户手动调整过尺寸后，保留 `userResized=true`，后续任务完成不覆盖用户尺寸，只更新内容适配方式。
- 选中节点后在右下角显示缩放手柄；拖动手柄实时预览尺寸，释放时只记录一条历史。
- 媒体节点默认锁定素材比例；按住 `Shift` 可自由调整宽高，提供“恢复素材比例”和“恢复默认大小”。
- 调整节点尺寸不得触发媒体重新加载、视频暂停或视口自动适应。
- 文本节点使用独立尺寸规则，默认比媒体节点更适合输入和阅读。
- 节点尺寸变更后，重新计算与该节点相连的端口和贝塞尔连线，但不改变其它节点位置。

### 8.2 图片和视频铺满节点

- 图片、视频预览占据节点主体区域，标题、状态和操作按钮放在轻量浮层或边缘栏中。
- 默认使用 `object-fit: cover` 铺满内容区；提供“完整显示/裁切填充”切换，用户选择后记忆到节点展示配置。
- 图片节点直接展示清晰缩略图，不再只显示图片图标和一块空白区域。
- 视频节点使用稳定的单一 `<video>` 元素，任务轮询只更新 `src`、状态和播放控制，不重复创建标签。
- 视频预览默认暂停并显示封面；点击播放后在节点内播放，鼠标移入显示播放、静音和放大控制。
- 已生成视频的封面、播放状态和当前时间在局部更新时保持，禁止因为状态刷新而闪回第一帧。
- 预览加载中显示一次性的骨架屏；加载失败显示错误和重新加载，不反复闪烁占位图。

### 8.3 放大预览

- 点击图片或视频主体打开预览层；预览层支持原比例、适应窗口、播放/暂停和关闭。
- 双击媒体或点击右上角放大按钮进入大图/大视频预览，不触发节点选中或拖动。
- 预览层使用当前资源 ID，不复制资源文件；关闭后回到原节点和原画布视口。
- 预览层打开期间，画布后台任务可以继续执行，关闭后不丢失任务状态。

### 8.4 音频节点和音频参考

- 音频节点使用横向卡片，主体展示名称、时长、播放进度、播放/暂停、静音和音量，不套用图片/视频比例。
- 音频波形可在元数据准备好后加载；未生成波形时使用稳定占位，不反复重建音频元素。
- 音频播放状态在节点移动、选择、面板切换和任务刷新时保持；同时播放多个音频时遵循统一策略，默认开始播放新音频时暂停上一条。
- 点击音频主体打开放大播放层，可拖动进度、查看文件信息和设置“背景音乐/动作节奏/声音参考”等角色。
- 音频参考只传给支持音频输入的模型；当前模型不支持时保留素材但标记“本次不使用”，不能静默提交无效参数。

## 9. 文本节点整框编辑

- 文本节点主体直接作为输入区，节点标题只保留类型、运行状态和必要操作。
- 单击文本主体进入编辑，支持多行输入、自动换行、滚动和快捷键。
- 文本内容变化使用防抖保存，失焦、`Ctrl/Cmd+Enter` 或点击保存时提交；`Esc` 取消未提交修改。
- 文本节点不再要求用户必须打开右侧检查器才能输入内容。
- 文本主体提供“放大编辑”按钮，使用独立编辑层承载长文本，支持字数、清空、保存和取消。
- 放大编辑层关闭后保留节点原位置、视口和选中状态。
- 文本内容作为文字 payload 传递给下游节点；不得将文本文件 ID 当作图片/视频/音频参考素材传递。
- 文本节点拖动只允许从标题栏或拖动手柄开始，输入区内的文字选择、复制、滚动不应触发节点拖动。

## 10. 节点精简和流程入口调整

短剧生产流程暂时取消默认入口，不删除已有画布中的历史节点和数据。

默认节点库只保留：

- 文本输入
- 图片输入
- 视频输入
- 音频输入
- 资产/素材引用
- 图片生成
- 视频生成
- 可选提示词处理

处理方式：

- 从默认新建模板、空白画布快捷入口和节点库首屏移除故事大纲、分集剧本、导演规划、分镜表、人工确认、成片整理等短剧流程节点。
- 将这些节点标记为隐藏/实验节点，保留数据解析和历史画布兼容能力，以后恢复流程时无需迁移旧数据。
- 新建画布默认只创建用户明确选择的节点，不自动生成一串没有实际输入意义的节点框。
- 不修改任务中心、豆包管理、登录、租户和模型网关模块。

AI 助手的操作范围限定在当前画布，可以：

- 根据创意创建节点或工作流。
- 根据创意生成文本、角色参考和场景参考节点，不自动创建完整短剧流程。
- 将资产连接到指定节点。
- 检查流程中缺失的素材或输入。
- 只重试失败节点，不重复执行已完成节点。

## 11. 主题和颜色自定义

支持主题预设：

- 灵帧经典：品牌蓝绿强调色。
- 深夜画布：深色沉浸式工作区。
- 明亮创作：接近小云雀的浅色工作区。
- 高对比度：适合长时间操作和无障碍使用。
- 自定义主题：用户选择强调色和画布风格。

主题统一使用 CSS 变量：

```css
--canvas-bg
--canvas-grid
--panel-bg
--panel-border
--node-bg
--node-border
--accent
--text-primary
--text-secondary
--connection-color
```

允许用户自定义：

- 画布背景色。
- 网格颜色、密度和显示开关。
- 强调色。
- 面板透明度。
- 字体大小。
- 节点色彩强度。
- 连线颜色和粗细。

固定不允许修改：

## 14. 补充交互细节与异常处理

### 14.1 拖动边界

- 节点标题栏按下后使用 Pointer Capture，指针离开节点或画布边界仍能继续完成拖动，结束时必须释放 capture。
- 节点拖到画布边缘 40px 范围内时，画布以低速自动平移；离开边缘立即停止，自动平移不得改变缩放比例。
- 自动平移过程中编辑器保持隐藏，连线跟随节点移动，不能出现节点移动而连线停留的情况。
- 节点拖动设置最小移动阈值 4px，区分“点击选择”和“开始拖动”；拖动状态下禁止触发节点内部按钮。
- 节点层级按最后点击/拖动的节点置顶，但不能遮挡连接端口、临时连线和预览放大按钮。
- 可选网格吸附默认关闭；开启后提供吸附间距和临时按住 `Alt/Option` 取消吸附，避免用户无法精确摆放。

### 14.2 选择、连线和删除

- 端口可点击区域不小于 18px，视觉圆点可以更小，但不能要求用户精准点击 13px 的圆点。
- 开始连线时显示临时连线；移动到可接受端口高亮，移动到不兼容端口显示禁止标识并禁止落点。
- 同一来源、目标和数据类型的重复连线不重复创建；连线失败时给出就地提示，不弹出阻塞式对话框。
- 单击空白处取消选择；`Ctrl/Cmd` 或 `Shift` 扩展多选；`Esc` 依次关闭菜单、取消连线、取消框选、取消拖动。
- 删除节点前区分“仅删除画布引用”和“删除项目资产”；默认只删除画布节点，不删除项目资产。
- 删除有下游连线的节点时提示将同时解除哪些连线；支持一次撤销完整删除动作。
- 框选只选中完全或可见区域内的节点，不能把被浮层遮挡的节点误选中。

### 14.3 保存、撤销和恢复

- 节点移动、尺寸变化、连线创建/删除、文本提交和素材替换各形成一个可理解的历史动作。
- 拖动过程中不连续写入历史；一次拖动在释放时只生成一条可撤销的“移动节点”记录。
- 保存状态明确区分“未保存、保存中、已保存、保存失败”；保存失败保留本地草稿并允许重试。
- 切换画布、关闭编辑器或退出沉浸模式前，不弹出重复确认；只有存在无法恢复的保存失败时才提醒。
- 应用刷新或异常退出后，优先恢复最近一次已保存视口、节点位置和文本草稿；恢复失败不覆盖原始画布数据。

### 14.4 素材拖放与加载

- 从项目资产拖入画布时显示放置预览，释放后节点左上角落在鼠标对应世界坐标，不因缩放产生偏移。
- 图片、视频、音频、文本文件按类型创建对应节点；文本文件导入后提取文本内容，不能把文件对象当作下游文字输入。
- 素材上传中显示单节点加载状态，上传完成后自动替换为预览；失败时保留节点并提供重试/移除操作。
- 素材不存在、权限失效或 URL 过期时显示明确的“资源不可用”，不能留下空白白框。
- 同一素材重复拖入允许建立多个画布引用，但不重复上传或复制项目资产。
- 图片/视频元数据尚未读取时先使用生成比例或默认比例，读取完成后平滑调整节点尺寸，不能让节点跳到画布原点。

### 14.5 键盘与窗口适配

- `Space + 拖动` 临时平移画布；`+/-` 缩放；`F` 适应画布；`Delete/Backspace` 删除选中节点；`Ctrl/Cmd+Z` 与 `Ctrl/Cmd+Shift+Z` 撤销/重做。
- 输入框、文本节点和放大编辑器获得焦点时，快捷键只作用于输入内容，不触发画布删除、缩放或平移。
- 预览层打开时，`Esc` 只关闭预览；关闭后焦点返回触发预览的节点或按钮。
- 窗口缩放、系统缩放比例变化和抽屉切换后，节点不被裁切；必要时只调整可视区域和浮层位置。
- 画布宽度不足时优先隐藏低频工具和状态文字，不能压缩节点到不可编辑尺寸。
- 拖动、缩放和播放控制提供可见焦点样式，颜色不能是唯一的状态提示。

### 14.6 运行和异常状态

- 运行节点后，用户可以继续编辑其它节点；当前节点显示运行状态，但状态层不能覆盖标题栏拖动区域和取消运行入口。
- 任务失败只影响当前节点，不清空上游文本、图片、视频和音频输入。
- 结果回传时保留旧版本，用户可以预览旧版本、切换当前版本或重新运行，不直接覆盖不可恢复。
- 视频播放、任务轮询和节点拖动互不抢占焦点；播放中的视频不因节点选中、面板切换或状态刷新而重置。
- 长时间任务显示“仍在运行”与最近更新时间；网络中断时进入可恢复状态，恢复连接后继续查询，不重复提交任务。

## 15. 依赖与待确认事项

以下事项不应在无限画布代码中自行猜测，开发时优先读取现有配置或能力描述；没有能力信息时隐藏不支持的选项，而不是显示后提交失败。

### 15.1 模型和通道能力

- 模型网关需要提供模型能力：文本/图片/视频支持、可接受的输入媒体类型、比例、时长、清晰度、数量和参数范围。
- 豆包通道需要确认实际可用的模型、账号组、账号选择、比例、时长、参考图/视频/音频支持情况。
- 如果模型能力接口暂时不能返回，前端只展示已有稳定参数；新增参数以配置驱动，不能在无限画布硬编码一套与管理中心不一致的列表。
- 余额、账号登录、模型可用性和租户权限沿用现有模块结果；无限画布只消费结果并显示状态。

### 15.2 文件和资产能力

- 确认本地上传接口支持的格式、大小、并发数和取消上传能力；前端根据返回的限制校验。
- 确认项目资产选择器能返回资产 ID、类型、预览地址、原始比例、时长和权限状态。
- 预览地址失效时需要统一的刷新/重新获取方式；不能在无限画布内复制资源鉴权逻辑。
- 文本文件提取需要明确编码、最大文本长度和提取失败提示；提取结果只进入 `prompt/textBlocks`。

### 15.3 任务和恢复能力

- 确认现有任务接口是否支持取消；不支持时使用“停止关注”语义，不伪造取消成功。
- 任务查询必须支持 `requestId` 或已有任务 ID 的幂等恢复，避免刷新、重连和重复点击产生重复任务。
- 结果回传必须能定位到 `canvasId + nodeId`；无法定位时进入运行现场的“待绑定结果”，不能覆盖其它节点。
- 任务状态枚举、失败原因、重试条件和不可重试原因需要与现有任务中心映射，画布只做展示和入口。

### 15.4 默认产品参数

- 默认图片/视频预览使用 `cover`，用户可以切换完整显示；默认视频暂停、默认音频不自动播放。
- 默认节点宽度、最小/最大尺寸、网格吸附开关、沉浸模式初始状态需要固定为一组默认值并保存用户偏好。
- 生成按钮默认只提交 1 个任务；批量生成必须作为明确的后续能力，不能因模型返回多结果而自动创建大量节点。

## 16. 验收标准

- 用户打开画布后 5 秒内可以开始一次创作。
- 空白状态首先显示“灵感，即刻成帧”。
- 不理解节点的用户也能通过输入框和快捷入口完成起步。
- 首屏可以直接添加本地/项目图片、视频、音频，选择可用模型和豆包参数，并看到素材预览与删除/替换操作。
- 点击生成并通过本地校验后立即进入无限画布，先看到节点和任务状态，不等待远程生成完成。
- 从首页创作台直接生成时始终新建画布；已有画布只有明确运行当前节点时才复用。
- 专业用户仍能拖拽节点、连线、分组、运行和查看现场。
- 画布元素、资产库、项目资产互不混淆。
- 项目资产可以拖到画布，并能回填生成结果。
- 节点编辑不大面积遮挡画布。
- 无限画布中央区域占满窗口，进入沉浸模式后只保留必要顶栏和画布。
- 展开左侧资源库或右侧检查器时以浮层覆盖，不导致节点位置、缩放比例和视口中心跳变。
- 节点标题栏开始实际拖动后，编辑器在同一帧隐藏；拖动结束后自动打开当前拖动节点的编辑器，已有编辑状态保留原对象与 tab，没有编辑状态则打开默认编辑页。
- 拖动节点离开画布边界仍能完成操作，靠近边缘时可自动平移，释放后只产生一条可撤销的移动记录。
- 没有实际位移的标题栏点击仍可选择节点，输入区内的文本选择不会误触发拖动。
- 拖动、缩放、平移过程中不调用全量画布重绘；释放后坐标可保存并可撤销。
- 运行视频节点时仍可新建画布、切换画布、创建节点、移动节点、滚轮缩放和平移。
- 任务状态轮询不会重建已有媒体元素，视频不会闪回、闪烁或丢失播放状态。
- 任务在提交中/排队中可以取消；不可取消阶段明确显示“停止关注”，不伪造取消成功；重试不会生成重复任务。
- 图片和视频内容默认铺满节点主体，节点比例与素材/生成比例一致，点击可放大预览。
- 音频节点有独立的播放、进度和参考角色交互，不套用图片/视频预览逻辑。
- 文本节点整个主体可直接编辑，长文本可放大编辑并正确以文字内容传给下游。
- 素材拖入位置与鼠标世界坐标一致，媒体元数据加载完成后节点尺寸平滑更新，不跳回原点。
- 无效连线、重复连线、素材失效、上传失败和任务失败都有就地反馈及恢复入口。
- 窗口缩放、面板切换、预览开关和运行状态更新不会抢焦点、重置视口或破坏当前编辑。
- 顶部主题、导入、导出按钮不再常驻显示重复文字，悬停/聚焦时有 Tooltip，按钮不会竖排或错位。
- 首屏生成不会覆盖已有非空画布；任务和节点通过 `requestId` 幂等恢复，结果无法定位时进入待绑定状态而不覆盖其它节点。
- 模型能力未知时隐藏不支持参数；模型、账号、文件限制和任务取消能力均沿用现有配置，不在无限画布内另造一套规则。
- 默认节点库不再展示短剧生产流程节点，但历史画布仍可打开、运行和保存。
- 主题切换不影响节点数据、任务数据和项目数据。
- 现有节点执行、任务回填和租户隔离能力保持不变。
- 其他页面和模块没有代码变更。
