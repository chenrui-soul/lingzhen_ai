# 无限画布阶段二：首屏创作台

日期：2026-08-30

## 本阶段范围

本阶段只优化无限画布首屏创作入口，不修改任务中心、豆包管理、登录、租户、模型网关或浏览器控制模块。

## 已完成

### 首屏一体化创作台

- 品牌文案统一为“灵感，即刻成帧”。
- 首屏支持文本创作、图片生成、视频生成三种创作类型。
- 快捷入口现在只切换创作预设，不直接创建无意义的短剧节点。
- 文本输入支持长文本、字数计数和 `Ctrl/Cmd + Enter` 提交。
- 输入草稿保存在当前画布数据中，刷新或切换后可以恢复。

### 参考素材

- 支持本机图片、视频、音频上传。
- 支持从当前项目资产库选择素材，选择过程在创作台内完成，不跳转资源库页面。
- 支持从左侧资源面板拖入首屏参考素材区域。
- 素材显示缩略图、文件名、格式和角色标签。
- 支持人物、场景、道具、动作参考、风格参考、首帧、尾帧等角色标记。
- 素材引用以媒体资产 ID 传递，不把媒体包装成文本文件。
- 支持移除素材和点击预览，最多保留 12 个参考素材。

### 模型与参数

- 复用已有 `routeControls`、账号池和模型能力数据。
- 按创作类型过滤模型，不复制模型网关或豆包管理逻辑。
- 支持模型网关/豆包通道、模型、账号分组、账号、比例、时长和模型能力参数。
- 参数变化保存在首屏创作草稿中。
- 没有可用模型、豆包账号或创意文字时，生成按钮保持可见但不可提交，并给出提示。

### 生成与新画布

- 点击“生成并进入无限画布”前先完成本地输入和配置校验。
- 校验通过后必定新建一个空白无限画布，不把首屏内容直接混入旧画布。
- 新画布自动创建创意/提示词节点、生成节点和已选择的参考素材节点。
- 节点之间保留直接输入关系，媒体素材以独立资产引用进入执行输入。
- 进入新画布后自动运行目标生成节点，任务仍通过无限画布统一执行入口提交。
- 原首屏画布的创作草稿保留，方便返回继续修改。
