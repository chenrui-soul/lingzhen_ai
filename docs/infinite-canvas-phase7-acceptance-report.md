## 本阶段覆盖的验收点

- 运行期间仍可编辑其它节点、切换画布、创建节点、移动节点、缩放和平移。
- 节点实际拖动时隐藏编辑器，结束后恢复编辑器。
- 视频和媒体状态刷新使用局部更新，不重建已有媒体元素。
- 首页创作台点击生成后创建新画布，不覆盖已有画布。
- 首屏包含素材、模型、参数和生成入口。
- 图片/视频按比例展示并支持放大预览；文本内容以文字 payload 传递。
- 新画布使用精简节点库，历史短剧画布保留完整节点和执行兼容。
- 删除连线不取消已执行任务；取消/停止追踪入口独立存在于运行记录。
- 任务重复运行有保护，取消后节点不会被异常处理改回失败。
- 顶部工具栏提供 Tooltip 与 `aria-label`，主题只影响无限画布显示。
- 任务、结果、画布、节点和租户绑定字段保持完整。
