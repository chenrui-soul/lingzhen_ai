# 灵帧 AI

灵帧 AI 由桌面创作客户端和管理中心组成。

## 目录

- `desktop/`：Electron 桌面客户端，负责创作、豆包账号协同、任务中心和本地工作台。
- `center/backend/`：Spring Boot 后端，负责身份、租户、模型目录、积分钱包、订单和任务账务。
- `center/frontend/`：管理中心前端，供管理员维护模型目录、用户和积分。

## 固定服务端口

- 管理中心后端：`9001`
- PostgreSQL：`5433`

## 安全说明

本仓库不包含本地缓存、账号 Cookie、数据库密码、API 密钥、Token、构建产物或安装包。
请根据各项目的示例配置文件创建本地配置后再运行。
